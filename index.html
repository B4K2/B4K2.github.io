Preprint // Mechanistic Interpretability

Architectural Inductive Biases Under Extreme Capacity Constraints: A Mechanistic Case Study of 60M-Parameter Language Models

PDF ↗ Code ↗

Faculty-advised team project. Trained twenty-four ~60M-parameter GPT-style models on 1B FineWeb-Edu tokens (250+ GPU hours) under a single-axis protocol comparing MHA/MQA/GQA/MLA, RoPE, MoE, and Muon vs. AdamW — isolating why mechanisms designed for 7B–70B models break when compressed.

  • MLA Rank Bound (Prop. 3): MLA's deficit at r=64 (PPL 33.84) is rank saturation. Widening to r=256 recovered -1.94 PPL, and a decoupled-RoPE branch (M29) reached 31.22 PPL at 2.7× lower KV cache than MHA.
  • Muon on GQA (Prop. 1): Plain Muon on GQA was a null (32.10 → 32.09). Shape-aware update scaling with retuned lr=0.01 (M28) unlocked 31.08 PPL (-1.01 PPL).
  • KDA Finite-State Recall Bound (Prop. 2): Linear attention trades exact recall for fixed-size state; LAMBADA recall collapsed to 0.116 while BLiMP grammar stayed top-tier at 0.782.
  • Perplexity ≠ Capability: Shared-expert MoE models (M14–M16) lead on downstream benchmarks (PIQA 0.608, ARC-Easy 0.485) despite worse perplexity.

Paper // Genomic Language Models

Mnemos-DNA: Long-Context DNA Language Model with K-mer Fast-Weight Memory

PDF ↗ Code ↗

Faculty-advised team project. Linear-attention (KDA) models scale to long DNA sequences but lose exact recall — the same finite-state bound found in the 60M study. Mnemos adds a k-mer fast-weight memory to restore it.

  • Exact recall restored to 64 kbp for only ~3% extra parameters.
  • 1 Mbp-context inference in 5.6 GB VRAM on an 8 GB laptop GPU.
  • Released weights on Hugging Face and a companion benchmark, recall-bench, on PyPI.
